# Document Processing

## Processing Stages
1. Extraction
2. Cleaning
3. Chunking
4. Classification
5. Embedding generation

## Chunking Rules
- preserve headers
- preserve semantic sections
- avoid arbitrary token splitting
- maintain chunk overlap

## Metadata Extraction
- department
- document type
- ownership
- recency
- tags

## Embedding Strategy
- batch embedding jobs
- cache embeddings
- regenerate on content change
