# Frontend UX

## Core Screens
- Search page
- Chat interface
- Document explorer
- Admin dashboard
- Maintenance insights

## UX Principles
- citation-first retrieval
- low cognitive load
- fast response times
- transparent AI behavior

## Search Result Requirements

Every result should display:
- authority status
- freshness status
- owner
- last review date
- citations
- ranking explanation

---

## Trust UX Principles

Users must understand:
- why a result appeared
- whether it is authoritative
- whether it may be stale

## Authority Visibility

Search results must display:
- authority status
- review recency
- owner
- department
- freshness indicators

Canonical documents should be visually distinct.

Deprecated documents should display warning indicators.
