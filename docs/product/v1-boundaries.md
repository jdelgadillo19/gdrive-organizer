# V1 Product Boundaries

## Included In V1

- Google Drive integration
- Folder scanning
- Recursive document analysis
- PDF support
- Google Docs support
- DOCX support
- Spreadsheet support
- Semantic organization recommendations
- Filename normalization recommendations
- Recommendation review UI
- Manual approval workflow
- Rollback support
- Recommendation explanations
- Confidence scoring

---

## Explicitly Excluded From V1

- Slack integration
- Multi-user RBAC
- Canon conflict resolution workflows
- AI document rewriting
- Autonomous file modification
- Enterprise audit systems
- Cross-tenant governance
- Live synchronization
- Automated canon enforcement
- AI-generated master documents
